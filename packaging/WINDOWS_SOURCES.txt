AMD's HIP runtime (amdhip64_7.dll), which ZLUDA runs on, is not bundled: AMD's Windows driver installs it.
NVIDIA DLLs are not bundled. install.ps1 downloads DLSS 310.7.0 from NVIDIA/DLSS
commit a291cc7d2cc642a51566f3dfd5376f635cd1b284, DLSS Ray Reconstruction 310.9.1 from commit
374959484e79a640feaba44c93ac8cfb0a03f5b5 and _nvngx.dll from NVIDIA driver 596.36.
URLs and SHA-256 hashes are pinned in install.ps1. NVIDIA license terms apply. The engine models
install.ps1 builds in d4r/engine hold values read from those DLLs: they are not part of this zip.
Included NVIDIA PTX-derived kernels (not covered by d4r licenses):
  d4r/kernels/*/hiluma_engine_*, rrlite_enc0_*, rrlite_dec0_*, rrlite_post_*, rrlite_downsample_*
                         NVIDIA's PTX from nvngx_dlss.dll with parts replaced by d4r code (kernels/tex) or translated
                         to HIP (kernels/native), compiled by ZLUDA or the HIP SDK's clang.
  d4r/kernels/*/cuda_dldn_engine_hkpn_output_kernel_*
                         NVIDIA's PTX from nvngx_dlssd.dll with parts replaced by d4r code (kernels/rr), compiled by
